네트워크관리사 2급 핵심 이론 노트

필기 및 실기 기본 개념 시험에 자주 출제되는 핵심 주제 모음

OSI 7 계층 핵심 정리

  • 7. 응용 (Application): HTTP, FTP, SMTP, DNS, DHCP (데이터)
  • 6. 표현 (Presentation): 암호화, 압축, JPEG, ASCII
  • 5. 세션 (Session): 연결 유지, API, NetBIOS, SSH
  • 4. 전송 (Transport): TCP(신뢰성, 3-Way Handshake), UDP(비연결성, 속도). PDU: 세그먼트
  • 3. 네트워크 (Network): IP, ICMP, ARP/RARP, 라우팅. PDU: 패킷
  • 2. 데이터링크 (Data Link): MAC 주소, 스위치, Ethernet, PPP. PDU: 프레임
  • 1. 물리 (Physical): 리피터, 허브, 케이블, 비트(Bit)

주요 프로토콜 포트 번호 (필기 필수)

• FTP: 20(데이터), 21(제어)
• SSH: 22
• Telnet: 23
• SMTP: 25
• DNS: 53
• DHCP: 67/68
• HTTP: 80
• HTTPS: 443
• SNMP: 161/162
• POP3: 110

• IPv4 클래스 구분:

  • Class A: 1.0.0.0 ~ 127.255.255.255 (기본 서브넷: 255.0.0.0 / CIDR: /8)
  • Class B: 128.0.0.0 ~ 191.255.255.255 (기본 서브넷: 255.255.0.0 / CIDR: /16)
  • Class C: 192.0.0.0 ~ 223.255.255.255 (기본 서브넷: 255.255.255.0 / CIDR: /24)

• 사설 IP 대역 (Private IP):

  • Class A: 10.0.0.0 ~ 10.255.255.255
  • Class B: 172.16.0.0 ~ 172.31.255.255
  • Class C: 192.168.0.0 ~ 192.168.255.255
★ 서브넷 계산 꿀팁: 사용 가능한 호스트 수 = 2(32 - CIDR) - 2 (네트워크 주소 및 브로드캐스트 주소 제외).
예) /26 인 경우 서브넷 마스크 = 255.255.255.192, 블록 크기 = 64, 호스트 수 = 62개.
핵심 장비 구분

• L2 스위치: MAC 주소 테이블 기반, VLAN 지원

• L3 스위치: IP 라우팅 기능 포함 스위치

• 라우터: 서로 다른 네트워크 연결, 최적 경로 설정 (RIP, OSPF)

네트워크 보안 용어

• Spoofing: IP/MAC/DNS 등을 속여 정상 사용자로 위장

• Sniffing: 네트워크 패킷을 몰래 도청/탈취

• DoS / DDoS: 대량의 요청으로 서비스 거부 상태 유발 (SYN Flooding 등)
